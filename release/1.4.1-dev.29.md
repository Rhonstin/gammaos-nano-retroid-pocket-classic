# 1.4.1-dev.29 — original Pocket Classic development checkpoint

Unofficial GammaOS Nano 1.4.1 / Core / Android 14 integration for the original
four-button Classic (`parrot`, board `<0x22 0>`). Not a Rev Q release.

New since dev.23:

- Updated bundled apps: RetroArch with pinned nightly cores, PPSSPP 1.20.4, Flycast 2.7,
  Aurora Store, Firefox Beta.
- New emulators: ARMSX2 (PS2), Dolphin (GameCube/Wii), Azahar (3DS), Vita3K (PS Vita),
  and DroidDeck for Steam games.
- Nano's Game column gains Steam Games, PlayStation 2, GameCube, Wii, Nintendo 3DS and
  Sega Saturn. PlayStation switches to SwanStation once the owner adds a PS1 BIOS.
- Controller profiles, touch overlays off, shader defaults, Flycast/Eden debug counters off.
- A Nintendo Switch entry appears when the owner installs Eden; the image ships the
  Mesa Turnip driver and Eden defaults the Adreno 613 needs, but not Eden itself.

**What is not included:** no console BIOS or firmware, no encryption keys, no games,
ROMs or disc images, and no Switch emulator. Everything bundled is open-source or
freely redistributable software in unmodified upstream form, pinned by SHA-256 with its
licence (see `THIRD_PARTY_NOTICES.md` and `apps.lock.json`).

Validated on one original unit (see `docs/VALIDATION.md`): permanent boot with a full
`system_a` hash match, userdata kept by the updater, and launches from Nano for Steam,
PS1 (with Quick Resume), PS2, GameCube, Wii, 3DS, Saturn, GBA, PSP and Dreamcast.
USB OTG storage remains untested.

Download all `system.sparse.img.part*` files with `release.json`, then reassemble and
verify with `python3 tools/join_image.py --manifest release.json`. For an existing
supported installation use `tools/update_classic.py` (without `--raw`); see
`docs/PUBLISHING.md` and `docs/INSTALLING.md`.

Development firmware with AVB authentication NONE, built by integrating public upstream
firmware, not a full AOSP rebuild. Upstream licences and notices continue to apply.
