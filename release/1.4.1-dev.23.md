# 1.4.1-dev.23 — original Pocket Classic development checkpoint

Unofficial GammaOS Nano 1.4.1 / Core / Android 14 integration for the original
four-button Classic (`parrot`, board `<0x22 0>`). Not a Rev Q release.

- Native Nano boots permanently; full system partition readback matched the image.
- Classic controller, display/audio, fan/performance and sleep integration.
- Quick Resume save compatibility and synchronization before native restart/off.
- Off-mode battery animation, actual backlight blank/wake and long-Power boot.
  The owner confirmed the physical display behavior and manual return to Nano.
- NFS linked-entry decoder repair and 32 KiB transfer workaround; R/W, rename,
  deletion and complete 259-file listings tested. FTP/implicit FTPS also tested.

Tested on one original unit with retained vendor/kernel and an already unlocked
bootloader. USB OTG storage remains untested. Initial installation is experimental;
the provided updater is for an existing supported port and retains userdata.
See `docs/VALIDATION.md` and `docs/INSTALLING.md` before selecting an installation path.

The image is development firmware with AVB authentication NONE. This is integration
of public upstream firmware, not a full AOSP rebuild. Existing upstream component
licenses/notices still apply. These local draft assets have not been published.
