# GammaOS Nano для Retroid Pocket Classic

Окремий проєкт для публікації неофіційного порту. Поточна контрольна версія —
**1.4.1-dev.23**, перевірена на оригінальній чотирикнопковій Classic.
Власник підтвердив батарею, гасіння/пробудження екрана та ручний запуск Nano.
USB OTG-сховище ще не перевірене. Rev Q цим профілем не підтримується.

У репозиторії — код, патчі, інструкції, тести та публічні хеші. Особисті резервні
копії, сирі журнали, серійний номер консолі, ROM-и й збереження сюди не входять.
Великі образи готуються окремими файлами для GitHub Releases.

- [Основний README](../README.md)
- [Збирання](BUILDING.md)
- [Оновлення та межі першого встановлення](INSTALLING.md)
- [Що перевірено](VALIDATION.md)
- [Публікація на GitHub](PUBLISHING.md)

Це інтеграція публічного GammaOS Core 1.4.1, а не повна компіляція AOSP.
Початкове встановлення експериментальне й відокремлене від updater, який
зберігає дані вже встановленої Nano. На GitHub нічого автоматично не публікується.
